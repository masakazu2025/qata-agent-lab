# 用語集（一般の言葉の推奨語）

一般の言葉で、言い方がいくつもあるものについて、このプロジェクトで使う言葉を決めます。意味は書きません（一般の意味のとおりです）。

- 技術用語は、広く通じる言い方をそのまま使います。英字やカタカナの言葉も避けません。日本語に訳した言葉を作りません（[working.md](../../../.claude/rules/general/working.md)）。
- 言い方が一つしかない一般の言葉と、「実行」「結果」のように一語では何のことか決まらない言葉は、載せません。
- 揺れを見つけたら、ここに足します。
- qata 固有の言葉は [domain.md](domain.md) にあります。

| 推奨語 | 使わない言い方 |
| --- | --- |
| モック | 偽物、偽の〜 |
| E2E テスト | 端から端までのテスト |
| イテレーション | 周回、N 周目 |
| 復旧・復旧する | 立て直し・立て直す |
| 事前条件 | 始める前の状態 |
| 対象バージョン | 有効な版 |
| スクリーンショット | スクショ |
| 期待結果 | 確認事項 |
