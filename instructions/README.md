# 移植用の指示書

ここで行った改善を、あとで本物の qata に入れるための指示書を置きます。issue を一件終えるごとに、一つ書きます。

## 誰が読むか

本物の qata で作業する AI エージェントです。ここでの経緯も、このリポジトリの中身も知りません。指示書だけを読んで、同じ変更を入れられるように書きます。

ここで直したファイルを写してもらうのではなく、指示書に沿って入れ直してもらいます。本物の qata はこのあとも進むので、ここのコピーと中身がずれていくためです。

## ファイルの名前

`<issue の番号>-<内容>.md`（例：`3-rename-gate.md`）。内容は英小文字とハイフン。

## 書くこと

| 見出し | 書くこと |
| --- | --- |
| 目的 | 何をよくするための変更か。困っていたことと、よくなること |
| 前提 | どのファイルの、どういう状態を前提にしているか。本物の qata で、それが変わっていないかを先に確かめてもらう |
| 手順 | 何をどう変えるか。ファイルと、変える前と後の例 |
| 確かめ方 | 入れ終わったあと、何を見れば正しく入ったと分かるか |
| 元の作業 | このリポジトリの issue と pull request へのリンク |

前提が本物の qata と合わないときは、無理に入れず、人に聞くように書きます。
